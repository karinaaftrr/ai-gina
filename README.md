# AI GINA — Petualangan Detektif Ginjal

Media pembelajaran interaktif berbasis *Learning Adventure* untuk siswa kelas 5–6 SD dan guru dalam rangka kegiatan pengabdian kepada masyarakat. Mengintegrasikan **Matematika**, **Statistika & Pengolahan Data**, **Konsep Sistem Pakar (Fuzzy Logic)**, dan **Edukasi Pola Hidup Sehat Ginjal**.

---

## Identitas & Desain
- **Karakter Utama**: AI GINA (Pendamping Belajar, bukan dokter)
- **Sebutan Siswa**: "Detektif Muda"

---

## 6 Misi Pembelajaran
1. **MISI 01**: *Mengenal Si Penyaring Darah* — Membaca tabel penyaringan ~180 L darah vs ~1,5 L urine (rasio 120×).
2. **MISI 02**: *Membaca Sinyal Tubuh* — Mengelompokkan data frekuensi & diagram batang interaktif.
3. **MISI 03**: *Menghitung Risiko* — Operasi penjumlahan & perkalian bobot gejala layaknya sistem pakar.
4. **MISI 04**: *Menjelajah Dunia Fuzzy* — Skala interval 0–100 dan logika derajat Rendah, Sedang, Tinggi.
5. **MISI 05**: *Menemukan Pola* — Statistika dasar: mencari nilai yang paling sering muncul (MODUS).
6. **MISI 06**: *Operasi Penyelamatan Ginjal* — Penyelidikan kasus puncak terpadu detektif muda.

## Cara Menjalankan Aplikasi

1. Pastikan Python 3 sudah terpasang.
2. Install dependensi (Flask):
   ```bash
   pip install -r requirements.txt
   ```
3. Jalankan aplikasi Flask:
   ```bash
   python app.py
   ```
4. Buka peramban (browser) dan akses:
   ```
   http://127.0.0.1:5000
   ```

## Standar Keselamatan Medis (Medical Safety)
Aplikasi ini ditujukan semata-mata sebagai sarana edukasi matematika dan kebiasaan sehat anak usia sekolah dasar. AI GINA bukan dokter dan tidak memberikan diagnosis medis. Hasil simulasi dinamai **"Tingkat Risiko Simulasi"** untuk tujuan pembelajaran.
